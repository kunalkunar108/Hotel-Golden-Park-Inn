# Hotel Golden Park Inn — Demo Website

A responsive static frontend concept for Hotel Golden Park Inn in Basukinath, Jharkhand.

## Preview locally
Open `index.html` in a browser. No build step, framework, API key, or environment variables are required.

## Deploy to Vercel
1. Import `kunalkunar108/Hotel-Golden-Park-Inn` into Vercel.
2. Select **Other** as the framework preset if prompted.
3. Leave Build Command and Output Directory empty for this plain static HTML project.
4. Deploy.

## Included
- Responsive homepage and navigation
- Room showcase cards
- Pilgrimage/location section with Google Maps search links
- Room enquiry form that prepares a WhatsApp message
- Mobile sticky enquiry bar
- SEO description and accessible form labels

## Before showing this to the hotel
- Replace illustrative photography with the property's approved photos.
- Confirm the exact address, contact number, room categories, amenities, rates, and temple travel time.
- In `index.html`, set `hotelWhatsApp` to the hotel's WhatsApp number using country code and digits only (no plus sign or spaces). It is intentionally blank, so the demo currently opens a generic WhatsApp share link.
- The form is not a booking engine and does not verify live availability.
